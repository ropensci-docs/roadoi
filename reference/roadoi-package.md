# R Client for the Unpaywall-API

What is this client for?: roadoi interacts with the Unpaywall data
service, which links DOIs representing scholarly works with open access
versions.

## Details

Use the
[`oadoi_fetch()`](https://docs.ropensci.org/roadoi/reference/oadoi_fetch.md)
function in this package to get open access status information and
full-text links from Unpaywall.

You are welcome to contribute to this package. Use GitHub's issue
tracker for bug reporting and feature requests.

More details about the Unpaywall API:
<https://unpaywall.org/products/api>.
