# Find OA copies with RStudio addin

An [RStudio addin](https://rstudio.github.io/rstudioaddins/) to call
[`oadoi_fetch()`](https://docs.ropensci.org/roadoi/reference/oadoi_fetch.md).
Shows up as "Find free full-texts" in the RStudio addin menu.

## Usage

``` r
roadoi_addin()
```

## Details

The addin works as follows:

1.  Copy up to ten line-separated DOIs into the text area

2.  Press the button "Run!"

3.  Click on the links in the table to download full-text
